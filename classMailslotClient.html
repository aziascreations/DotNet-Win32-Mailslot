Creates a mailslot client connected to the given UNC path.

Parameters
fullUncPathRemote mailslot server's full UNC path.
Format: \{host}\mailslot\{path}
isAsync
mustExistChecks if the mailslot you specified exist before we attempt to connect to it.
Default: true
Exceptions
ArgumentExceptionThrown if the given UNC path is invalid.
It gets thrown by the constructor and MailslotUtils.ComposeMailslotUncPath.
IOExceptionThrown if you specified or left mustExist as true and the server doesn't exist or can't be connected to.
Win32ExceptionThrown if we got an invalid SafeFileHandle while opening the mailslot in the Win32 APIs.

Checking if a mailslot exist on a remote computer may slow down the program's execution on extremely slow networks since we may end up doing the check twice.
